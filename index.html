Embarca IFMG

O que é o projeto

O Embarca IFMG é um sistema web desenvolvido para organizar e exibir informações essenciais do IFMG – Campus Ibirité, com foco em transporte público, rotina acadêmica e comunicação visual institucional.

Objetivo

Centralizar informações que hoje estão espalhadas ou são difíceis de acessar, oferecendo uma solução simples, visual e acessível para alunos e servidores.

Modos de utilização

  • Modo Monitor: exibição automática para TVs e monitores.
  • Modo Interativo: navegação completa em celular, tablet ou PC.

Tecnologias utilizadas

  • HTML5
  • CSS3 (responsivo)
  • JavaScript puro
  • API pública de clima
