# 🌐 Comunidade IFMG

A **Comunidade IFMG** é um projeto acadêmico idealizado desde **2022**, surgido a partir da vivência dos próprios estudantes no **IFMG – Campus Ibirité**.  
Com o avanço dos conhecimentos técnicos adquiridos ao longo do curso, a ideia pôde finalmente ser estruturada e colocada em desenvolvimento de forma prática e organizada.

O projeto tem como objetivo **auxiliar os estudantes do IFMG Campus Ibirité**, centralizando informações e oferecendo ferramentas que facilitem o dia a dia acadêmico. Além disso, a Comunidade IFMG também serve como uma **ferramenta de aprendizado** para seus desenvolvedores, permitindo a aplicação real dos conteúdos estudados.

---

## 🎯 Objetivo do Projeto

- Facilitar o acesso a informações relevantes para a comunidade acadêmica  
- Centralizar serviços e funcionalidades úteis em um único ambiente  
- Propor soluções simples para problemas reais vivenciados no campus  
- Aplicar, na prática, conhecimentos de desenvolvimento front-end  

---

## 🧩 Estrutura do Projeto

A Comunidade IFMG foi pensada como uma **plataforma modular**, permitindo a adição de novos serviços ao longo do tempo.

### Módulos disponíveis atualmente:
- **🚌 Embarque IFMG — Modo Monitor**  
  Exibição contínua e automática de informações sobre os horários de ônibus em telas fixas no campus.

- **📱 Embarque IFMG — Modo Interativo**  
  Interface interativa que permite ao usuário consultar individualmente as informações de transporte.

### Módulos previstos:
- Horários de Aula  
- Calendário Acadêmico  
- Feedback  
- Mídia  
- Outros serviços futuros  

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
- Templates front-end
- Dados simulados

> ⚠️ Este projeto possui foco exclusivo em **front-end**, não utilizando backend, banco de dados ou APIs externas.
